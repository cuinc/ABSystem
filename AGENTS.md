# ABSystem - Unity AssetBundle Management Library

## Cursor Cloud specific instructions

### Overview

This is a Unity C# project (AssetBundle management system). It has no external package managers, no CI/CD, and no automated test suite. All compilation, building, and testing is done through the Unity Editor.

### Environment

- **Unity Editor**: 2022.3.62f3 installed at `/opt/unity/2022.3.62f3/Editor/Unity`
- **Unity Hub**: installed at `/opt/unityhub/unityhub`
- **.NET SDK 8.0**: installed for standalone C# compilation verification
- **Unity License**: required before opening the project. The user must sign into Unity Hub via the Desktop pane and activate a Personal (free) license.

### C# compilation check (without Unity)

A standalone compilation check can be run using `dotnet build` with a temporary project referencing Unity managed DLLs. The key references are:
- `/opt/unity/2022.3.62f3/Editor/Data/Managed/UnityEngine.dll`
- `/opt/unity/2022.3.62f3/Editor/Data/Managed/UnityEditor.dll`

Required define constants: `UNITY_EDITOR;AB_MODE;UNITY_5;UNITY_2017_1_OR_NEWER`

Do **not** reference both `UnityEngine.dll` and `UnityEngine.CoreModule.dll` simultaneously — they cause CS0433 type conflicts.

### Unity batch mode

Once a license is activated, open and compile the project in batch mode:
```
/opt/unity/2022.3.62f3/Editor/Unity -batchmode -nographics -projectPath /workspace -logFile /tmp/unity.log -quit
```
Check `/tmp/unity.log` for compilation results.

### Running the project

Per the `readme.md`:
1. Open `ABSystem/Builder Panel` from the Unity menu
2. Configure build settings and click `Build`
3. Ensure the `AB_MODE` scripting define symbol is set (already configured in `ProjectSettings/ProjectSettings.asset`)
4. Run the `main.unity` scene

### Key gotchas

- The project originally targeted Unity 4.x/5.x. Code uses `#if UNITY_5 || UNITY_2017_1_OR_NEWER` to select the 5.x builder path; under Unity 2022 this compiles via `AssetBundleBuilder5x`.
- `AssetBundleBuilder4x` is wrapped in `#if UNITY_4 || UNITY_4_6` and is excluded from compilation.
- Deprecation warnings for `WWW` (replaced by `UnityWebRequest`) and `AssetBundle.mainAsset` are expected but non-blocking.
- The `.gitignore` excludes `.csproj`, `.sln`, and `ProjectVersion.txt`; these are regenerated by Unity.
